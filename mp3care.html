mp3care

In development

A Windows tool for reviewing large MP3 collections and previewing fixes before applying them.

Testing pending

The current build is still awaiting testing.

Reviewing a collection

The leading-silence tool shows how long tracks take to start and previews a trim for each affected song. You can compare waveforms and listen to both versions before deciding which tracks to change.

Other views cover trailing silence, uneven volume, song tags, and cover art. There’s also a tool designed to split a hidden or bonus song from the track it was bundled with. The project is designed to keep a recoverable original and preserve the existing MP3 encoding when trimming audio.
