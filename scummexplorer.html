Inside the workbench

The explorer reads resources from your own game files. These development views show how it displays rooms, scripts, dialogue, and sound.

The room browser uses thumbnails to make locations easy to recognize. The costume viewer lays out the poses used to animate characters. The script and text views let you inspect the instructions and lines of dialogue behind a scene.
